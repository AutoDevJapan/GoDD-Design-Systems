# GoDD Design-Systems

業種・色・雰囲気から、画面の配色や文字、余白のルールをまとめた `DESIGN.md` を探せる公開カタログです。設計の参考にしたり、AIに画面を作ってもらうときの資料として使ったりできます。

- [公開カタログ（日本語）](https://autodevjapan.github.io/GoDD-Design-Systems/) · [公開カタログ（英語の画面）](https://autodevjapan.github.io/GoDD-Design-Systems/en/)
- [公式 Wiki](https://github.com/AutoDevJapan/GoDD-Design-Systems/wiki) — カタログの使い方、データの取得、開発と検証
- [索引データの配布](https://github.com/AutoDevJapan/GoDD-Design-Systems/releases/tag/index-pages)
